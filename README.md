Name: Tomislav Ćosić

## Description
The weather app allows the user to type in any location to check the current weather conditions such as temperature, type of weather and others. Alongside the information, an appropriate background image and weather icon will be displayed. It also displays weather conditions for the next 5 days for the chosen location which includes the temperature taken at approximately 12:00 and the maximum and minimum temperature for that day.

## Specifications
The weather app uses the Open Weather Free API to fetch information about weather anywhere in the world. For acquiring the longitude and latitude of a specific location, the app uses the Geocoding API. For display of weather conditions of 5 days in advance the 5 Day / 3 Hour Forecast API is used. The API key for all of the aforementioned APIs was acquired through the Open Weather API website for free personal use.
